== Third-party intellectual property

This project may be inspired by classic tick-based fantasy MMORPG mechanics, but implementation and content must remain original.

Do not commit copied or extracted third-party game content, including:

* source code
* maps
* models
* textures
* music
* sound effects
* dialogue
* quest text
* logos
* proprietary data files

Every new third-party dependency or asset must have its license identified before merge.

Dependencies must have terms compatible with this repository's intended use.

== Secrets

Never commit:

* credentials
* API tokens
* private keys
* production passwords
* secret connection strings

Use environment variables, local ignored configuration, or GitHub Secrets where appropriate.

Example configuration files must contain placeholders only.
